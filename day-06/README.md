# Day 06 — TypeScript + React

## Deliverables
```text
day-06/
├── typescript/
│   ├── employee-types.ts
│   └── type-exercises.ts
├── react-app/
│   ├── src/
│   ├── package.json
│   ├── index.html
│   ├── tsconfig.json
│   └── vite.config.ts
└── README.md
```

The `typescript` directory includes typed interfaces and TypeScript practice. The `react-app` directory contains the Employee Management Dashboard: dashboard metrics, employee list, search, filter, add, edit, delete, validation, reusable typed data, props, state, events, forms, conditional rendering, and lists.

## Run
```bash
cd react-app
npm install
npm run dev
```
