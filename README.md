# 10-Day Intern Technical Training & Domain Assessment Program

> **Self-Study • Hands-on Practice • Technical Assessment**

## 📌 Overview

This repository contains the complete work for the **10-Day Intern Technical Training & Domain Assessment Program**.

The program is designed to develop practical technical skills through:

* Self-study and technical learning
* Hands-on programming exercises
* Daily practical assignments
* Git and GitHub-based development
* Problem solving and debugging
* Documentation and technical decision-making
* A final project and technical presentation

The program covers both **AI/ML** and **Web Development** paths, with a strong focus on practical implementation and the ability to explain the submitted work.

## 🎯 Program Objective

During the 10 working days, interns are expected to independently study the assigned material, complete exercises, build practical applications, solve technical problems, and develop a final project.

By the end of the program, interns should be able to:

* Write and understand clean, maintainable code
* Solve programming and algorithmic problems
* Work with Git and GitHub
* Build applications using modern development technologies
* Work with APIs and databases
* Analyze and process data
* Build basic machine-learning models
* Develop frontend and backend applications
* Debug and troubleshoot technical issues
* Document implementation and technical decisions
* Explain important parts of their submitted code
* Present and demonstrate a working final project

## 🔀 Git & GitHub Workflow

All work should be maintained using Git.

Basic workflow:

```bash
git clone <repository-url>

git checkout -b feature/day-01

# Make changes

git status
git add .
git commit -m "feat: complete day 01 assignment"

git push origin feature/day-01
```

Use meaningful commit messages and keep commits focused on logical changes.

Example:

```text
feat: add employee management CLI
feat: implement employee search
fix: handle invalid employee input
docs: update day 01 README
refactor: improve employee service
```

## 🐛 Problem-Solving & Debugging

Before asking for help, follow this process:

```text
Understand the Problem
        ↓
Read the Error
        ↓
Check Documentation
        ↓
Search for Possible Solutions
        ↓
Try a Solution
        ↓
Debug
        ↓
Ask for Help if Still Blocked
```

Interns are expected to research and troubleshoot problems independently before requesting assistance.
